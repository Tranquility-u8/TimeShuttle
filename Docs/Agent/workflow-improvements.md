# 工作流改进记录

只记录证据支持的可复用改进，避免把每个任务复盘追加到常驻上下文。原始度量保存在 `Saved/Agent/Metrics/`，口径见 [workflow-metrics.md](workflow-metrics.md)。

## 首轮试行

- 改进：任务起止计数、显式暂停和按需阶段记录，由脚本汇总，Agent 只读取短摘要。
- 原因：区分重复调查、依赖遗漏、测试返工与工具等待；当前会话日志已很大，禁止每次完整扫描。
- 验证方式：先累计 5–10 项真实任务，再对约 5 项同类任务比较质量、经过时长和用量；尚无节省比例结论。
- 保留条件：采集不妨碍开发，并能帮助定位重复返工。数据不足时保留未知，不扩大成复杂监控系统。

后续每条结论只需包含：问题、单项改变、相关 TaskId、同类任务观察、保留或撤回决定。重复结论合并进对应 SOP 后，在此留简短索引。
