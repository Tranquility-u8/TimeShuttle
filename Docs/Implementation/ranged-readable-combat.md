# 远程敌人：可读战斗节奏

日期：2026-11-02。需求：减少远程敌人无原因行走、射击与躲闪，让玩家能够观察、预判并利用行动间隙。用户已授权按讨论方向实施；本轮先完成普通远程兵的节奏与掩体闭环，不增加新兵种或小队指挥系统。

状态：五个 AI 资产已定向保存；图表整理、六蓝图最终编译与无制作工具冷验证通过。下列运行结果来自本轮实际 PIE，不能替代人工手感验收。

## 原因与行为变化

原远程树的攻击任务挂有两秒 Cooldown。冷却期间任务失败，Selector 会落入 `Evade`，执行随机最佳四分位选位。因此，即使现有位置有效，攻击后的冷却也可能触发移动。掩体条件还允许未受伤敌人仅因暴露满 2.5 秒就转移。

当前普通射击链为：有效目标与距离检查 → 停止移动 → 面向目标 → 瞄准等待 → 再检查目标与视线 → 原生攻击与蒙太奇 → 恢复等待。仅距离不合适才让攻击分支返回失败、进入原选位链；缺失目标、无可用攻击令牌不会触发随机躲闪。完成回调在发起攻击前绑定，迟到回调检查任务仍在执行。

| 配置 | 当前默认值 / 规则 |
| --- | --- |
| 普通射击准备 | 0.65 世界秒 |
| 允许原地交战的距离 | 400–1600 cm；超出后复用原 EQS 重新选位 |
| 射击恢复 | 原生攻击完成后等待 0.9 ± 0.1 世界秒 |
| 原攻击节点 Cooldown | 0；恢复等待保持当前分支，不再通过失败触发 Evade |
| 普通重新选位 | `SingleResult`，保留原射界、寻路与距离评分 |
| 掩体进入 | 新近受伤或低于原 35% 血量阈值，仍受掩体冷却约束；移除单纯暴露时长触发 |
| 掩体候选 | 保留最佳四分位内选择，供已有分布式预约分散占位；选中后保持本轮位置 |
| 隐藏等待 / 探头准备 | 1.0 / 0.45 世界秒 |
| 探头距离 / 到达容差 | 140 / 10 cm，探头与返回均关闭 StopOnOverlap，避免两个位置同时被判为已到达 |
| 探头射击 | 每次沿用两次原生攻击调用，间隔 0.38 世界秒；每次调用前检查目标和视线 |
| 掩体循环 | 在同一实际可达返回点完成两轮；最多尝试一次镜像侧身位置，不能无限左右重试 |
| 掩体释放冷却 | 6 世界秒 |

返回点是停止移动后缓存的实际到达位置，避免强行返回贴近障碍、胶囊无法精确到达的 EQS 请求坐标。原 `CoverLocation` 继续承担预约候选位置，不把本地返回点写回占位协议。保留原 275 cm 预约互斥、失败/Abort 清理和 5% 掩体恢复。

## 搜索兼容性

实际掩体测试暴露了共享 Controller 的依赖：躲进掩体导致丢失视线，原搜索定时器会提前终止探头任务。

`AIC_Enemy_Base.EventGraph.SeekAttackTarget` 仅在 `IsTakingCover && IsCoverOccupied` 时，以 0.25 世界秒重新安排同一个搜索回调，并保存到原 `SeekAttackTargetTimer`。感知重新获得目标时，原清理仍能取消该句柄。释放/中断掩体后，恢复原搜索路径。未占用掩体的敌人，包括近战兵，走原分支。没有延长全局感知记忆，也没有新增读取玩家隐藏位置的机制。

## 运行证据与测试夹具

修改前后均使用 `Map_Test` 的实际 Shooter、原生行为树、自然发现目标和原生弹丸。基础对比临时关闭玩家受伤并暂停近战脑，只调整玩家到已确认可见、可导航的站位，没有直接调用远程 Attack。

- 22 秒对比均有 199 次采样：移动采样从 114 次降至 2 次，掩体状态从 97 次降至 0 次；仍有自然开火。早期这组对比保留自动 QTE，因此不用于认证精确世界秒射速。
- 后续隔离测试在 PIE 实例上关闭自动 QTE。真实远程弹丸使玩家生命 `2 → 1`；没有向玩家注入伤害。
- 受伤夹具向敌人施加原生通用伤害 5 点。搜索兼容性修复后，同一掩体内观察到两组两发射击、实际侧身/回位和预约释放；后续不同候选中也覆盖了不可用探头位置的退出。
- 遮挡夹具仅在 PIE 中临时将一个原有静态物体作为墙，并暂时限制敌人平移，隔离“丢失射界”条件。稳定遮挡约 8.4 秒期间没有新弹丸；物体和移动配置随后恢复。
- 玩家贴近至约 230 cm 后触发重新选位并恢复射击。
- 正式组件 `ToggleTimeAbility` 进入约四现实秒 FullStop，世界时间仅增加约 0.056 秒，无新弹丸；退出后恢复正常间隔，没有集中补发。此项是正式能力接口测试，不是 Q 键输入回归。
- 共享 Controller 修复后的近战回归：暂停 Shooter、恢复实际近战脑并移动玩家到可见近距离，原生近战使玩家生命 `2 → 1`，无注入伤害，场内没有 Shooter 弹丸。

最终收尾结果：

- Blueprint Assist 刷新尺寸、整理、添加/更新结构化注释后再次整理，并进行编辑器目视复核。四张修改过的蓝图在忽略走线 reroute 后，连接、引脚默认值与类型的比较一致；Controller 另外 16 张图表的布局保持。
- 四张修改蓝图及两类正式敌人共六张蓝图，最终编译均为 `errors=0 warnings=0 status=3`。行为树在功能检查点保存，四张蓝图在布局/注释后再次定向保存；没有保存关卡、角色或无关资产。
- 关闭编辑器后，不加载 BlueprintOps、LabAuthoring 或 Blueprint Assist，重新加载保存版本；六张相关蓝图冷编译窗口无错误/警告。
- 无制作工具的最终组合 PIE 记录 281 次采样：自然弹丸命中使玩家生命 `2 → 1`；敌人受原生伤害 5 点后，在同一掩体流程中产生两组两发射击；约 3.984 现实秒 FullStop 内世界时间增加约 0.056 秒，没有新弹丸，恢复后没有集中补发。最终占位/预约标记清除，世界倍率为 1。
- 冷验证未发现 Blueprint runtime/Accessed None 错误。最终 PIE 已结束，编辑器停留在 `Map_Test`，脏资产为零。
- [本机验收摘要](../../Saved/Agent/RangedReadableCombat/validation-summary.json)中的 16 项核对全部通过。原始运行、编译和布局比较文件位于同一个忽略跟踪目录；它们不随仓库克隆分发。

初次冷测试夹具使用默认编辑器属性变更通知时，正式能力调用未进入预期时停。运行时夹具改用 `PropertyAccessChangeNotifyMode.NEVER` 后，无制作工具的独立时停与组合复测通过。该失败记录与早期观测脚本/API 错误、修复前编译错误均保留，不计入最终通过，也没有为此修改正式时间能力资产。

## 验证边界

本轮没有新增躲闪动画、压制/近失弹感知、独立兵种、小队进攻名额或最后目击位置记忆系统。保留原有调查与搜索框架。人工移动瞄准手感、所有关卡掩体适配、大数量压力、打包与联网尚未验收。

人工试玩清单：

1. 在 `Map_Test` 开始 PIE，接近远程敌人，观察停步瞄准、开枪与射击间隙是否清楚。
2. 向敌人开火并利用遮挡，观察受伤后的掩体转移、两轮探头和回位；换边绕侧检查射界变化。
3. 贴近敌人，确认它会重新拉开交战距离，且不反复左右抽动。
4. 主动进入、退出时停，观察射击是否平顺恢复。重点反馈移动频率、射击停顿与探头节奏是否合适。
