# FPS 蹲起与低掩体

2026-10-15：按用户“独立完成、符合 FPS 蹲起射击”的要求，在 UE 5.6.1 教程地图完成实施与 PIE 验证。设计依据为本次明确需求；未刷新 Drive 设计快照。

## 行为与参数

| 项目 | 当前值/行为 |

| 站立胶囊 | 半高 88 cm、半径 48 cm，保持原值 |
| 蹲姿胶囊 | 半高 55 cm，总高 110 cm |
| 站立/蹲姿视点 | 相对胶囊底部 160 / 95 cm；平地实际世界 Z 包含约 2.15 cm 的离地间隙 |

## 实现边界

修改资产：

- `/Game/Blueprints/Player/BP_FPCharacter`
- `/Game/Blueprints/AI/Shooter/BP_ShooterNPC`

原有原生下蹲已经改变胶囊，但第一人称 SpringArm 挂在 Mesh 的 Camera 插槽上，动画及原生网格补偿使实际视点没有产生应有的高度差。新增 `UpdateCrouchView` 以实际 `bIsCrouched` 为目标，平滑 65 cm 的视点落差，并根据当前动画 Camera 插槽的高度修正网格相对 Z。第一人称手臂、相机和武器保持现有挂接体系。

更新顺序显式设置为 Movement → Mesh → Player → SpringArm，避免读取上一帧动画插槽造成视点抖动。过渡使用 Real Time，因此 FullStop 和 BulletTime 不会把蹲起拖成世界慢动作。原生碰撞胶囊负责底部位置、碰撞和站起重试；视点平滑不直接缩放碰撞体。

`CheckCanStand` 用 Pawn profile 检测完整站立胶囊，中心按当前胶囊半高差上移并忽略自身。保留历史变量 `CanUncrouch` 的反向含义：TRUE 表示被阻挡。删除原先下蹲检查定时器，避免状态检查与输入事件不同步。当前检测尺寸与玩家胶囊一致；以后修改角色尺寸时须同步检查这些参数。

同日后续按用户要求改为切换操作。`ToggleCrouch` 检查实际 `bIsCrouched` 或原生 `bWantsToCrouch` 请求，任一为真则调用 StopCrouch，否则调用 BeginCrouch；不使用独立 FlipFlop 状态，因此冲刺、复活和低顶阻挡不会使切换状态失配。低顶下按 C 请求站起时仍保持实际蹲姿，空间清空后自动站起；低顶下重复按 C 仍保持安全的站起请求。输入仍经过原有对话/存活门禁。

Shooter 的攻击方向从目标 Actor 中心改为 `GetActorEyesViewPoint`。玩家原生 `BaseEyeHeight=72`、`CrouchedEyeHeight=40` 与稳定后的实际视点对应，使站立时能暴露于低墙上方，蹲下时由真实墙体挡住弹丸。原有目标/武器有效性检查与伤害链保留。

Blueprint Assist 用于新增节点的尺寸刷新与局部排版，新增结构化注释。对局部排版锚定造成的重叠进行了位置修正，并恢复无关节点原布局。保存前对图表语义进行比较：允许纯走线 reroute 重建及空 Key 输出默认值的编译规范化，功能连接与输入默认值保持一致。

## 验证记录

运行环境：`Map_TrainingRoom`，现有 Stage 7B 战斗区域。受控测试暂停敌人行为树、固定双方位置；射击仍经过正式武器/弹丸/伤害入口，没有用注入伤害冒充实弹命中。

| 检查 | 证据 |
| --- | --- |
| 姿态与移动 | 11 项通过：视点、胶囊、脚底、速度、恢复站姿、冲刺进入、下蹲取消冲刺、蹲姿转冲刺、FullStop 蹲起 |
| 边界与慢动作 | 8 项通过：低顶阻止站起/冲刺/跳出、移除低顶后站起、快速反复蹲起、BulletTime 蹲起、倍率恢复为 1 |
| 玩家射击 | 7 项通过：Enhanced Input 注入按住/释放/瞄准/开火；站立手枪命中敌人 500→475，蹲下被实际低墙挡住，站起再命中 475→450；时停弹悬停、释放后仍被墙挡住 |
| 敌人射击 | 正式 Attack 蒙太奇触发实际弹丸：玩家站立 100→99、蹲姿 99→99、再站立 99→98；测试把剩余受击次数临时设为 100，避免途中死亡，未改资产默认值 2 |
| 复活 | 单独通过正式 ApplyDamage 触发死亡，检查复活恢复 Health=2、存活状态和站姿；这是注入伤害的边界测试 |
| 可视核查 | 编辑器中检查新增函数/保护分支/瞄准注释；PIE 观察站立越过低墙、蹲下被墙挡住，以及正常距离下的蹲姿持枪画面 |
| 保存与冷加载 | 两资产定向保存，相关蓝图编译 0 错误/0 警告；独立命令行进程冷加载复核参数与编译。地图及无关资产无待保存修改 |

本机临时脚本、图表快照、备份和逐帧记录位于被忽略的 `Saved/Agent/FPSCrouch/`。关键结果为 `pose-test.json`、`edges-test.json`、`cover-test.json`、`hostile-test.json`、`respawn-test.json`、`save-report.json`、`cold-verify.json`。

切换操作的追加验证在当前 `Map_Test` PIE 中进行，记录位于 `Saved/Agent/CrouchToggle/`；此前教程射击表记录的是初版按住操作。追加的 13 项测试全部通过，通过 Enhanced Input 注入覆盖长按不反复切换、松开保持蹲姿、再次按下站起、低顶阻挡/重复请求/清除阻挡后的站起、冲刺后的切换及复活后的切换。只保存玩家蓝图，保留用户原有的三个未保存地图外部 Actor 包。

调查期间曾出现测试夹具问题：未初始化交互焦点就调用拾取、用短 Actor 名调用命令误选蓝图预览对象、同帧设置瞄准并立即开火。最终测试分别初始化 Focus、使用完整 PIE 对象路径、等待相机更新；这些早期结果不计入通过记录。保留原日志用于区分测试脚本错误与玩法错误。

冷加载仍有 14 条既有 Manny PoseAsset 过期警告；PIE/编辑器仍有原动画的重复 DefaultSlot 等警告。本次未修改动画资产，不宣称全工程日志零警告。验证不覆盖完整游戏打包、所有武器或多人同步；未改变精度/后坐力数值，也未新增自动贴掩体/探头功能。
